Data Population Order

Populate once and keep rows in PostgreSQL. Respect foreign key dependencies (no CSV / demo-seed pipeline):

1. Countries (one-time insert; list via GetAllCountries) 2. Cities (needs Country) 3. Stadiums (AddStadium / UpdateStadium; needs City) 4. WorldCup (create tournament year) 5. Groups (create groups A–H, etc.) 6. Teams (assign country → group) 7. Coaches (one per team) 8. PlayerPositions (startup lookup: Goalkeeper, Defender, Midfielder, Forward) 9. Players (squad per team) 10. Matches (schedule: teams + stadium + date) 11. Users (for betting; DevAdmin/DevUser in Development) 12. Bets (after matches scheduled) 13. BetResults (created when admin resolves bets after full time)

Operational Notes

Demo tournament seeding (DemoSeedService, SeedController, embedded CSVs) and CSV bulk import endpoints were removed. List APIs for countries, cities, and stadiums remain for Teams and Schedule UIs.

Entity Details — Match Domain

Match.cs

  • Links two Teams (home/away)
  • Assigned to a Stadium
  • Has date/time for scheduling
  • Parent for Goals, Cards, TeamStats

TeamStats.cs

  • Per-team stats for a match
  • Possession, shots, points
  • Used for standings calculation

Goal.cs

  • Scoring Player reference
  • Minute of goal
  • Own-goal flag

Card.cs

  • Player who received card
  • Yellow or red
  • Minute of card

Entity Details — Betting Domain

Bet.cs

  • User places prediction on Match
  • Predicted outcome (home win, draw, away win, score, etc.)
  • Created before match starts

BetResult.cs

  • One-to-one with Bet
  • Points awarded after match resolution
  • Aggregated for leaderboard
